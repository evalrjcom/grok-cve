# 2.11 XXE (CWE-611)

CWE: CWE-611 (https://cwe.mitre.org/data/definitions/611.html)
Root cause: XML parser resolves external entities or DTDs supplied by the attacker.
Source → sink: Upload/API XML → parser with external entities enabled → file/SSRF via entity.
Code smells / review questions
- Grep: DocumentBuilderFactory, SAXParser, lxml without resolve_entities=False.
- Are DTD and external entities disabled?
- Smell: default JVM/XML parser settings.
Fix pattern
- Disable DOCTYPE/DTD/external entities; shared hardened parser factory; prefer JSON.
Vulnerable shape (educational)

Fixed shape

Detection ideas
- Any XML/SOAP/SAML/Office XML/RSS ingest is in scope; unit-test factory rejects entities.
OSCP / report angle
- Report parser configuration gap and recommended factory flags. No entity payloads that read host files.
